# Space Timeline Events equally by index, not proportionally by time

Timeline Events sit a fixed distance apart on the track, so 4000 BC to 250 BC (3,750 years) takes the same width as 1844 to 1845 (one year). Spacing proportional to time was rejected because the events cluster after 1498, and a proportional track would crush most of them together while leaving long empty stretches in the Indigenous period. The distortion is made visible with Gap labels, and the spacing lives behind `model/scale.ts` so an alternative stays possible.
