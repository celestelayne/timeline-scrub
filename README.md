# Trinidad & Tobago Timeline — Scrub

A full-viewport, scrubbable timeline of the cultural history of Trinidad & Tobago (4000 BC → 1940). Built from the coordinate system outward: position first, then motion, input, and rendering.

Stack: React, TypeScript, Vite, `d3-scale`. Tests with Vitest.

## Scripts

```bash
npm run dev     # start the dev server
npm run build   # typecheck and build
npm run lint    # oxlint
npm test        # vitest (once)
npm run sync    # fetch the Google Sheet and regenerate src/data/events.json
```

## Content

Content lives in a public Google Sheet. `npm run sync` fetches it as CSV, validates it, and writes `src/data/events.json` (committed; see `docs/adr/0002-sheet-content-via-build-time-sync.md`). A bad row fails the sync with its sheet row number and leaves the file untouched. To read from a different link, such as a "Publish to web" CSV, set `SHEET_CSV_URL`.

The sheet's columns: `Display date`, `Start year` (negative for BC), `Period`, `Cultural Series`, `Event title`, `Description` (blank line between paragraphs), `Place`, `Related Site`, `Reference`, `Media`. `--` and empty cells mean no value.

## Structure

```
src/
  data/        events.json (generated by `npm run sync`), markers.ts, types.ts
  model/       coordinates.ts, scale.ts, format.ts, gaps.ts, markers.ts   (pure: no React, no DOM)
  hooks/       usePosition.ts, useInput.ts, useViewportWidth.ts
  components/  Track.tsx
  App.tsx, main.tsx
scripts/       sheet.ts (parse and validate), sync.ts (fetch and write)
```

Rule: nothing in `model/` imports React. Tests sit beside the code they cover (`model/coordinates.test.ts`).

## Coordinate model

One source of truth, `pos`: a float index into the event list (`0 … N-1`). Everything else is derived from it.

```
input → target → (ease each frame) → pos → scale → px / year → render
```

| Module | Responsibility |
| --- | --- |
| `src/data/markers.ts` | Groups `events.json` into Markers (one per distinct year) and exposes their years. |
| `src/model/markers.ts` | `groupMarkers`: one Marker per year, holding every Timeline Event at that year. |
| `src/model/coordinates.ts` | `pos ↔ year`, linear interpolation between neighbouring events. Knows nothing about pixels. |
| `src/model/scale.ts` | `pos ↔ px` via `d3-scale`. Events are equally spaced (90px) by index, playhead at viewport centre. Knows nothing about time. |
| `src/hooks/usePosition.ts` | `target → eased pos`. Inputs only write `target`; `pos` chases it by 0.18 per frame. No snapping yet. |

Equal index spacing is deliberate (see `docs/adr/0001-equal-index-spacing.md`). Spacing lives behind `scale.ts`, so changing it is a one-function swap. `pos` indexes Markers, not events.
